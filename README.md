# 🌍 Smart Trip Planner

Smart Trip Planner is an intelligent travel planning application that creates personalized and optimized travel itineraries based on user preferences such as destination, budget, and interests. It uses real-time data like maps and weather to make travel planning easy and efficient.

---

## 🚀 Features

- 🧭 Personalized itinerary generation  
- 📍 Route optimization using Google Maps  
- 💰 Budget estimation (travel, food, stay)  
- 🌦️ Weather updates  
- 🏨 Booking integration (extendable)  
- 🤖 AI-based recommendations  

---

## 🛠️ Tech Stack

- Frontend: HTML, CSS, JavaScript  
- Backend: Python / Node.js  
- Database: MySQL / MongoDB  
- APIs: Maps API, Weather API
